# Звуки предметов

> [!IMPORTANT]
> **Статус**: Поддерживается `<br>`
> **Минимальная версия**: 1.4

## Настройка категорий звуков

В конфиге создайте секцию `[item_pickup_sounds]` для определения категорий звуков:

```ini
[item_pickup_sounds]
weapon = interface\pickup_items\weapon_    ; категория "weapon" - загрузит все звуки с префиксом "weapon_"
ammo = interface\pickup_items\ammo_        ; категория "ammo" - загрузит все звуки с префиксом "ammo_"
food = interface\pickup_items\food_        ; категория "food" - загрузит все звуки с префиксом "food_"
medkit = (ваш путь до звуков)
bottle = (ваш путь до звуков)
```

Система автоматически загрузит все звуки из папки `gamedata\sounds\`, соответствующие указанному префиксу (Вы можете указывать свой кастомный путь до звуков и создавать свои различные категории под предметы).

## Настройка звука для предмета

В секции предмета добавьте параметр `snd_on_take`:

```ini
[wpn_ak74]
snd_on_take = weapon              	; будет проигрываться случайный звук из "weapon"

[bread]
snd_on_take = interface\pickup_items\bread_pickup  ; прямой путь к конкретному звуку

[ammo_5.45x39_fmj]
snd_on_take = ammo                	; использовать категорию "ammo"
```

## Когда проигрываются звуки

Звуки проигрываются при следующих действиях:

- Взятие предмета с земли
- Перемещение предмета в слот/пояс/рюкзак
- Выброс предмета из инвентаря
- Выкладывание предмета в торговое окно

Если звук не задан, используется стандартный звук интерфейса.
